# SunnPOS React UI

React-based frontend for **SunnPOS**, a modern Point-of-Sale system.

This project provides the user interface for managing products, categories, customers, inventory, and sales through the SunnPOS API.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- React Router
- Axios
- CSS / Tailwind CSS
- ESLint

## 🏗️ Project Architecture
